## 해석

- `tools/save_result.sh cmp_bench_ref` 와 `tools/cmp_all.sh` 가 두 줄로 나뉘어 입력돼 save_result.sh 는 사용법만 찍고 끝났고, `cmp_all.sh` 만 따로 돌았다. 터미널 출력을 그대로 옮겨 이 파일을 만들었다(헤더는 손으로 채움).
- Quill v13.1.0, spdlog v1.17.0 원본 벤치마크를 같은 머신·같은 조건으로 처음 나란히 잰 결과. 원본은 g++ `-O3`, logx 는 `-O2`.
- **hot path 지연 (p50 / p99.9, ns)**

  | 로거 | numbers 1T | numbers 4T | string 1T | string 4T |
  |---|---|---|---|---|
  | Quill | **10 / 38** | **20 / 82** | **12 / 65** | **26 / 126** |
  | `LFLOG` | 28 / 386 | 68 / 504 | 32 / 451 | 74 / 378 |
  | `LFLOG_TEXT` | 267 / 574 | 480 / 1104 | 126 / 457 | 252 / 775 |
  | async | 367 / 861 | 442 / 1212 | 118 / 497 | 204 / 655 |
  | sync buffered | 252 / 2061 | 424 / 6909 | 116 / 1803 | 212 / 6398 |
  | spdlog async | 287 / 749 | 490 / 1597 | 216 / 669 | 464 / 1372 |

  - `LFLOG` 대 Quill: p50 은 2.7~3.4배, p99.9 는 3~10배 느리다. 공개값만 보고 적었던 "한 자릿수 느리다"는 p50 기준으로는 틀렸고 약 3배다.
  - 차이는 분포 모양에서 크다. Quill 은 p50~p99 가 10→14ns 로 평평한데 `LFLOG` 는 28→69(p75)→103(p90)→141(p99)ns 로 계속 올라간다(numbers 1T). 1스레드라 CAS 경쟁은 없으므로, 쓰는 슬롯을 바쁜 대기 중인 로깅 스레드가 바로 읽으면서 생기는 캐시 라인 왕복이 후보다(추정, 아직 안 잼).
  - `LFLOG` 대 spdlog async: p50 은 6~10배 빠르고 p99.9 도 1.5~3.6배 낫다. logx 의 나머지 방식(`LFLOG_TEXT`, async, sync buffered)은 p50 이 spdlog 와 비슷한 수준.
  - 앞 측정(`2026-11-03_091720_cmp_bench`, logx 만)에서 `LFLOG` numbers 1T p50 이 99ns 였는데 이번엔 28ns. 같은 코드라 실행 간 편차(주파수·배치)로 보이고, "numbers 가 string 보다 p50 2배" 현상도 이번엔 28 vs 32ns 로 사라졌다. 이 노트북에서는 한 번 측정으로 p50 을 확정하기 어렵다.
- **처리량 (400만 줄, flush 까지, M줄/s)**: Quill 4.67, spdlog async 2.78, `LFLOG` 2.98, `LFLOG_TEXT` 3.57, async 3.67, sync buffered 3.50.
  - `LFLOG` 는 Quill 의 0.64배, spdlog 보다 1.07배. 앞 측정(2.99)과 같아 재현된다. 상한은 로깅 스레드의 `%g` 포맷팅.
  - Quill 은 큐가 128KB → 128MB 로 계속 커지며(무제한 큐) 호출자를 막지 않는다. logx 는 고정 크기 큐라 조건이 완전히 같지는 않다.
- **spdlog bench.cpp (25만 줄, M/s)** — spdlog `basic_*` 는 동기 파일 로거라 같은 성격인 sync buffered 와 비교하는 게 맞다.

  | | 단일 | 1스레드 | 4스레드 |
  |---|---|---|---|
  | spdlog basic | 6.22 | 6.06 | 3.53 |
  | sync buffered | 10.06 | 9.99 | 6.69 |
  | `LFLOG` | 7.68 | 10.65 | 10.77 |
  | `LFLOG_TEXT` | 12.09 | 12.50 | 17.98 |
  | async | 11.88 | 12.08 | 6.29 |
  | sync direct | 0.82 | 0.79 | 0.93 |

  - sync buffered 가 spdlog 동기 로거보다 1.6~1.9배 빠르다. level-off 는 spdlog 131~144 M/s, logx 523~848 M/s (logx 는 레벨 검사가 인라인).
